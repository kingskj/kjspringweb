# 2026-05-03 작업 일지 - 서버 agent trace nodes[] 적재

## 개요

- 작업 범위: `turtlepick-agent-core` trace 파일 payload 확장
- 목적: 기존 endpoint/root 중심 trace에 요청 내 method chain `nodes[]`를 추가
- 진행 방식: Claude 선제안, GPT 딴지/보정/최종 반영

## 핵심 결정

- `methodId`를 node 식별자로 쓰지 않는다.
- 요청 내 호출 인스턴스 식별자는 `callId`로 두고, 부모 관계는 `parentCallId`로 표현한다.
- `methodId`는 node의 메서드 매핑값으로만 둔다.
- 이번 단위에서는 args/result/sql/error 전문 캡처를 제외한다.
- 개발/검증 편의를 위해 node에 `fqcnMethod`를 `f` 필드로 함께 출력한다.

## 변경 내용

- `MethodFrame`에 `callId`, `parentCallId` 추가.
- `CompletedNode` 신규 추가.
- `RuntimeTraceContext`가 `nextCallId`, `traceStartNanoTime`, completed node 목록을 관리.
- method exit 시 완료 node를 누적.
- `TraceLogSerializer`가 `nodes[]`를 callId 오름차순으로 직렬화.
- node JSON 필드:
  - `i`: callId
  - `p`: parentCallId
  - `m`: methodId
  - `f`: fqcnMethod
  - `st`: trace 시작 기준 start offset ms
  - `et`: trace 시작 기준 end offset ms
